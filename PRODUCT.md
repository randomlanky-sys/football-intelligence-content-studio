# Football Intelligence & Content Studio - PRODUCT.md

## Product Vision
An AI-powered football match analysis and content creation studio that transforms raw match data into compelling, evidence-linked tactical breakdowns and publish-ready content packs for creators, analysts, and teams.

## Core Value Proposition
Democratize professional football analysis by combining AI-powered event tagging, video synchronization, and tactical breakdown generation with automated content creation - turning hours of manual work into minutes of insightful, shareable content.

## Target Audience
- Football content creators (YouTubers, bloggers, podcasters)
- Sports analysts and commentators
- Football clubs and academies
- Sports journalists and media outlets
- Football enthusiasts seeking deeper tactical understanding

## Key Differentiators
1. **AI-Powered Analysis**: Automatic event detection and tactical pattern recognition
2. **Evidence-Linked**: Every insight backed by timestamped video evidence  
3. **Content Automation**: One-click generation of social posts, articles, and reports
4. **Multi-Platform**: Seamless export to YouTube, Twitter/X, TikTok, Instagram, Facebook
5. **Professional Grade**: Broadcast-quality analysis tools previously only available to pro teams

## Core Features
- Automatic event tagging (goals, shots, tackles, passes, etc.)
- Video synchronization across multiple angles
- Tactical heatmaps and formation analysis
- Player tracking and movement visualization
- Template-based content generation (match reports, highlight reels, tactical breakdowns)
- Social media optimized exports (vertical video, thumbnail generation, caption suggestions)
- Evidence linking (click any insight to see the exact video moment)
- Export formats: CSV, JSON, video clips, social media posts, blog articles

## Technical Stack
- Frontend: Next.js 15 (App Router), React 19, Tailwind CSS
- Backend: Fastify-based microservice architecture
- Database: Supabase (PostgreSQL with real-time subscriptions)
- Storage: IndexedDB (local), Dropbox, Zapier workflows
- APIs: YouTube Data API, X (Twitter), Snapchat, TikTok, Instagram, Facebook
- Testing: Playwright E2E, Vitest unit testing
- Deployment: Railway (primary), Render (secondary)

- User retention: 70% weekly active users

- Conversion rate: 40% free-to-paid conversion within 30 days
