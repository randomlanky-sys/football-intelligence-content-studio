Your mission is to design and progressively build an original, production-quality football match analysis and content creation platform. The product must transform football match evidence into structured data, transparent analysis, tactical explanations and publish-ready content. Do not simply reproduce an existing product. Study publicly observable workflows, identify user problems and develop an original implementation, data model, user experience and competitive advantage. ## 2. PRODUCT VISION Build a local-first football analysis platform that allows users to: 1. Create projects, teams, players, competitions and matches. 2. Load authorized local match footage. 3. Tag football events manually using a configurable event taxonomy. 4. Synchronize match time with recording time. 5. Edit clips and annotate tactical moments. 6. Executive product definition Football Intelligence &amp; Content Studio is a responsive, local-first football video analysis and storytelling workspace for creators who want to transform authorized match footage and structured data into evidence-backed tactical breakdown videos and reusable social-media content packs. The product is not merely an AI tactical-analysis demo or a generic video editor. Its core value is an integrated workflow: footage/data → synchronized evidence → clips and observations → tactical annotations and animation → AI-assisted candidate insights → human review → storyboard and narration → editorial approval → render and output quality checks → finished video and social content. Primary launch audience: independent football content creators producing tactical breakdown videos. Secondary audiences: coaches and independent analysts. Primary product outcomes: (1) tactical breakdown videos, and (2) social-media content packs derived from approved analysis. Initial platform: responsive web application optimized for desktop and Android browsers. A native Android application is deferred unless evidence proves responsive web insufficient. Experience: premium dark tactical studio, restrained pitch-green accent, high-contrast overlays, keyboard/mouse precision on desktop and touch-first controls on Android. Business model: freemium local editing with optional paid cloud AI, rendering, backup and synchronization. Trust principle: evidence before claims; human control before publication; privacy before convenience. 1.1 Product principles Evidence before interpretation. Every generated tactical claim should link to supporting footage, event data or explicit human observation. Human authority. AI output is a proposal until reviewed and approved by a human. Local-first utility. Users should be able to explore core local workflows without mandatory account creation or cloud upload, within real browser/device limits. One project truth. Video, data, tracking, annotations, narration, evidence and exports share one versioned project model. No silent damage. Never silently discard edits, switch player identity, shift timing, overwrite a newer version or imply a failed export succeeded. Uncertainty is visible. Uncertain tracking, pitch calibration, imported data alignment and AI claims are marked as such. Progressive complexity. Guided beginner-friendly flows coexist with flexible expert editing. Cost transparency. Cloud/billable tasks show relevant quotas, estimated cost/credits and status before or during work. Privacy by design. Private footage and scripts are excluded from routine diagnostics by default; external processing requires informed consent. Independent verification. Implementation is not accepted solely on the implementer's claim. Evidence-led scope. Release thresholds and model capability claims must be demonstrated, not invented. Rights-aware creation. Uploading footage does not itself establish permission to use or distribute it. 2. Scope and product boundary 2.1 Core workflow Create a local or authenticated project.
