Core contracts [P] Timebase (closes REV-005). Project clock is int64 microseconds, never float seconds. Each asset keeps native timescale + per-frame PTS table (VFR-safe, stored as a typed array blob). Frame stepping uses the table, not +1/fps ; seek rounds half-even to frame boundaries. Match clock ↔ media time uses piecewise-linear clock_mappings per period with ≥2 anchors and a stored residual; drift beyond tolerance sets Sync Needs Review . Pitch (closes REV-006). Metres, origin at bottom-left corner when the home team attacks left→right in period 1; default 105×68, configurable. attack_dir stored per team and period. Homography (3×3) per camera-shot segment with state none | calibrated | stale | uncertain ; pitch-anchored annotations are unavailable unless calibrated . Provenance. Every event/observation carries source ∈ {import, human, ai} , revision , supersedes_id . Human corrections never overwrite raw rows. Evidence staleness (closes REV-009). insight.evidence_hash = hash of referenced record revisions. Approval stores the hash; any mismatch flips status to stale and invalidates export approval. Project file. studio.project/1 JSON (+ media manifest with SHA-256 fingerprints, no bytes). Forward-only migrations with golden-file tests. 7. Data model Local stores mirror these names.
